1STEP 1 · THE PROBLEM

What was still broken after Inception V3?

By 2015, Inception V3 had introduced BatchNorm, factorization, label smoothing, RMSProp — many fixes. But one ghost remained: the vanishing gradient problem. As networks got deeper, gradients shrunk to near zero by the time they reached the early layers. The early layers couldn't learn anymore.

📐 The Vanishing Gradient Problem · What Goes Wrong

deeper = early layers stop learning
📞
Simple Way to Think About It

Like a phone call passed through 50 people

Imagine a teacher whispers a correction to student #50 ("you got the answer wrong"). Student #50 whispers it to #49, who whispers it to #48… by the time the message reaches student #1 at the front, it's so faint nobody hears it. Student #1 never learns. That's the vanishing gradient — early layers don't get a strong correction signal, so they stop improving.

2STEP 2 · THE SKIP CONNECTION IDEA

Add the input directly to the output: y = F(x) + x

Microsoft's insight: let the input "skip" the layers and add itself to the output. The layers only need to learn the small change to add. If the layer is unhelpful, F(x) → 0 and the input just passes through unchanged.

🧮
Before ResNet vs After ResNet
y = F(x)  →  y = F(x) + x
The +x is the skip connection · the network learns the residual (the change), not the full output

📐 Without Skip vs With Skip · Side by Side

notice the red shortcut arrow
🛗
Simple Way to Think About It

Like having a "stay on this floor" elevator button

Without skip: every floor in a 50-floor building must change something. Even when staying still is the right answer, the floor is forced to make a change. With skip: every floor has a "stay on this floor" button. If the floor's change isn't helpful, F(x) becomes zero and the elevator stays exactly where it was. Doing nothing is now an easy option.

2.5STEP 2.5 · INTRODUCING THE TERM "RESIDUAL"

The word "residual" simply means: the small change added on top

Forget the formula for a minute. The word residual simply means "the leftover" or "the small change added on top of what's already there." That's the whole idea — every block in ResNet is just adding a small, useful change on top of what came before.

Remember This One Line

Residual = the small change added on top of what's already there

y = F(x) + x
x
what we already have
(sketch · dull photo · empty room)
F(x) · the residual
the small change to add
(details · color boost · furniture)
y = F(x) + x
the better result
(drawing · vibrant photo · decorated room)
2.6STEP 2.6 · INSIDE A REAL IMAGENET TRAINING PASS

Now let's see exactly how this happens with an ImageNet photo

An ImageNet photo of a cat is already a clear picture — there's nothing missing in it. So what does "add a small change" mean inside the network? The answer: x is not the photo itself. x is the network's current understanding of the photo — its working notes. Each residual block reads those notes, adds one tiny extra observation, and passes the richer notes forward. Three examples below show exactly how this happens at three different depths inside the same forward pass.

💡

The trick to understand

The photo enters the network once, at the start. After the first few layers, the photo is converted into a feature map — think of it as the network's notes about the photo, like "I see fur, edges, ears, two eyes, whiskers."

x = these notes (the current understanding). Every residual block reads the notes, adds a small extra observation (that's F(x)), and passes the updated notes forward. The photo itself doesn't change — but the notes get richer at every block, until the final block can confidently say "this is a Persian cat" out of 1000 possible classes.

How Training Teaches F(x) What To Add

F(x) starts as random noise · the network is shown 1.28 million labelled ImageNet photos · with each photo it makes a guess, sees how wrong it is, and slightly nudges every F(x) in the right direction · until each block has learned exactly what small change to add.

3STEP 3 · IDENTITY BLOCK

When input size = output size · just add directly

In ResNet-50, when the conv layers don't change the spatial size or channel count, we can simply add the input x directly to the output. No transformation needed. This is the Identity Block.

📐 Identity Block · Skip Path is Just a Wire

input shape = output shape · direct add
🔌
When To Use Identity Block
When the conv layers preserve both spatial size and channel count · skip path is just a wire
🚗
Simple Way to Think About It

Like a car with two parallel roads to the same destination

The main road (conv path) does the heavy work — turns, lane changes, scenic detours. The shortcut road (skip path) is a straight line with no turns — same start, same end. Since both roads end at the same destination (same shape), you can simply add the two arrivals together. No need to bend or stretch the shortcut road.

4STEP 4 · CONVOLUTION BLOCK

When input size ≠ output size · reshape the skip path

When conv layers change the spatial size or channel count (e.g. between stages), input and output don't have matching shapes — you can't just add them. The fix: put a 1×1 convolution on the skip path to reshape x so it matches the output shape. This is the Convolution Block.

📐 Convolution Block · Skip Path Has a 1×1 Conv to Match Shape

input shape ≠ output shape · reshape skip path

Cheat Sheet For Your Students

The decision rule is dead simple

Question: Does the conv path change the shape (spatial size or channels)?
If NO → use Identity Block (skip path is just a wire)
If YES → use Convolution Block (skip path needs a 1×1 conv to reshape x)
Everything else (the 3 main convs) is identical in both blocks.

(expand channels back)
Every single block in ResNet — Identity or Convolution — follows this 1×1 → 3×3 → 1×1 sequence. The first 1×1 squeezes the channel count so the expensive 3×3 conv works on a smaller tensor. The final 1×1 restores the channel count. This "bottleneck" design is what makes deep ResNets computationally feasible.
